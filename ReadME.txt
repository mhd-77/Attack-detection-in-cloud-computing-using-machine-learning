# CloudAtk-ML: Cloud Attack Detection System

This repository contains **CloudAtk-ML**, a hybrid cyber-attack detection platform for cloud environments that merges XGBoost and Isolation Forest models using the UNSW-NB15 dataset.

## 📁 Repository Contents

* **`attack detection in cloud computing using machine learning.zip`**: Contains all the system source code, files, trained models, and dependencies.
* **`setup_guide_video.mp4`**: A complete video tutorial explaining how to install the environment, configure the database, and run the system.

## 🛠️ Quick Start

1. Extract the `project_code.zip` file.
2. Follow the step-by-step instructions provided in the `video.mp4` video to install the requirements and set up your Anaconda environment and run `app.py`.

## 🤝 Need Help?

If you face any issues during the installation or need any assistance running the project, please feel free to reach out to me!

# نظام CloudAtk-ML لكشف الهجمات السحابية

هذا المستودع يحتوي على نظام 
**CloudAtk-ML**، وهو نظام هجين ذكي لكشف الهجمات السيبرانية في البيئات السحابية 
يعتمد على دمج نموذجي XGBoost و Isolation Forest 
باستخدام مجموعة بيانات UNSW-NB15.

## 📁 محتويات المستودع

* **`project_code.zip`**: يحتوي على الأكواد البرمجية الكاملة للنظام، الملفات، النماذج المدربة، والمتطلبات.
* **`setup_guide_video.mp4`**: مقطع فيديو توضيحي يشرح خطوة بخطوة كيفية تهيئة البيئة، إعداد قاعدة البيانات، وتشغيل النظام.

## 🛠️ البدء السريع

1. قم بفك الضغط عن ملف `project_code.zip`.
2. اتبع التعليمات المشروحة خطوة بخطوة في فيديو `setup_guide_video.mp4`
 لتهيئة بيئة برمجية داخل برنامج أناكوندا 
وتشغيل ملف `app.py`.
